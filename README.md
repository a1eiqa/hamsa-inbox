# همسة

تطبيق ويب عربي للرسائل المجهولة. ينشئ كل مستخدم رابطًا خاصًا بصفحته، ويمكن لأي زائر يحمل الرابط إرسال رسالة من دون حساب. تظهر الرسائل في صندوق وارد خاص، وعند نشر رد يظهر الرد والرسالة معًا على الصفحة العامة. يستطيع صاحب الحساب حذف الرسائل أو إيقاف استقبالها من الإعدادات.

## التشغيل على جهازك

يتطلب Node.js 24.11 أو أحدث. يشغّل الأمر التالي التطبيق وقاعدة SQLite محلية من دون تثبيت حزم إضافية.

```sh
npm start
```

مع تثبيت Node.js وحده، شغّل `node scripts/build.mjs` ثم `node scripts/serve.mjs`.

افتح `http://127.0.0.1:4173`. تُحفظ بيانات التجربة في `.data/` داخل المشروع. لا تشحن مجلد البيانات أو ملفات البيئة إلى مستودع عام.

## نشر نسخة مستقلة

يمكن حفظ المصدر في مستودع GitHub عام. يحتاج تشغيل الحسابات وصندوق الوارد إلى Cloudflare Worker وقاعدة D1، أو استضافة تدعم نفس بيئة التشغيل. [توثيق GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

1. أنشئ قاعدة D1 بتشغيل `npx wrangler d1 create hamsa-inbox` بعد تسجيل الدخول إلى Cloudflare.
2. انسخ `wrangler.example.jsonc` إلى `wrangler.jsonc` واستبدل `YOUR_DATABASE_ID` بمعرّف القاعدة.
3. شغّل `npm run build` ثم `npx wrangler d1 migrations apply DB --remote`.
4. شغّل `npx wrangler deploy` وشارك الرابط الذي يعرضه الأمر. [توثيق إعداد Wrangler](https://developers.cloudflare.com/workers/wrangler/configuration/)

تتضمن النسخة الحالية صفحات الحسابات، والوارد، والملفات العامة، وتحديد معدل المحاولات الأساسية. احتفظ بكلمة المرور في مدير كلمات المرور الذي تستعمله، إذ إن التسجيل الحالي يستخدم اسم المستخدم وكلمة المرور ولا يتطلب بريدًا إلكترونيًا.
